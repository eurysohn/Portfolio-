# 🚀 배포 가이드 - Fly.io Web Dashboard 사용

## 현재 상황
- ✅ LLM 코드가 로컬에 모두 구현됨
- ✅ Git commit 완료
- ❌ Fly CLI 권한 오류로 배포 불가
- ❌ Git push 권한 오류

## 해결책: Fly.io Web Dashboard에서 직접 배포

### 방법 1: Fly.io Dashboard (가장 쉬운 방법)

1. **Fly.io 대시보드 접속**
   - https://fly.io/dashboard/personal 열기
   - 로그인

2. **앱 찾기**
   - "enterprise-text-to-sql-agent" 클릭

3. **환경 변수 설정**
   - 왼쪽 메뉴에서 "Secrets" 클릭
   - "New Secret" 버튼 클릭
   - Name: `OPENAI_API_KEY`
   - Value: `your-openai-api-key-here`
   - Save 클릭

4. **코드를 GitHub에 push** (터미널에서)
   ```bash
   cd /Users/eurysohn/Desktop/coding/Portfolio-/enterprise-text-to-sql-agent
   git push origin main
   ```
   
   만약 credential 문제가 있다면 GitHub Desktop 사용하거나:
   - GitHub.com에서 repo 열기
   - "Upload files" 클릭
   - 변경된 파일들 업로드

5. **Fly.io에서 GitHub 연결 & 배포**
   - Dashboard에서 "Deploy" 탭
   - "GitHub" 연결
   - "Redeploy" 클릭

### 방법 2: 로컬에서 Docker로 직접 빌드 (고급)

```bash
cd /Users/eurysohn/Desktop/coding/Portfolio-/enterprise-text-to-sql-agent

# Docker 이미지 빌드
/usr/local/bin/docker build -t enterprise-text-to-sql-agent .

# 로컬에서 테스트
/usr/local/bin/docker run -p 8080:8080 \
  -e OPENAI_API_KEY='your-openai-api-key-here' \
  enterprise-text-to-sql-agent

# 브라우저에서 테스트
open http://localhost:8080/health
```

로컬 테스트에서 `"llm_enabled": true`가 보이면 성공!

### 방법 3: 가장 빠른 임시 해결책

지금 당장 배포가 안 되더라도, **코드 자체**가 포트폴리오의 핵심입니다:

1. **GitHub에 코드 올리기** (위 방법대로)
2. **README.md 업데이트**
   - LLM integration 설명 추가
   - 코드 스니펫 포함
   - Architecture diagram 추가

3. **면접/인터뷰 시**
   - 코드를 보여주면서 설명
   - "로컬에서는 작동하는데 Fly CLI 권한 문제로 deployment pending"
   - 실제 구현 능력을 증명 가능

## 배포 확인 방법

배포가 완료되면:

```bash
curl https://enterprise-text-to-sql-agent.fly.dev/health
```

**예상 결과:**
```json
{
  "status": "ok",
  "generator_mode": "hybrid",
  "llm_enabled": true,
  "llm_model": "gpt-4o-mini"
}
```

## 로컬 Git Push 문제 해결

만약 git push가 계속 안 된다면:

1. **GitHub Desktop 사용** (가장 쉬움)
   - GitHub Desktop 열기
   - Repository 선택
   - "Publish branch" 또는 "Push origin"

2. **또는 credential 재설정**
   ```bash
   git config credential.helper osxkeychain
   git push origin main
   ```
